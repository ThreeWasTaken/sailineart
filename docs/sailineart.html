SaiLineArt

Draw and edit vector paths point by point with seven tools, shared shortcuts, and reversible transforms. This guide describes the behavior currently available in PhotoCraft.

SaiLineArt is the complete tool suite. SaiLine is the individual tool for drawing straight segments.

Create your first path

  1. Choose SaiCurve for a smooth curve or SaiLine for straight segments.
  2. Click the canvas to place control points. The preview follows the pointer from the last point.
  3. Set the base width from 0.7 to 30 px, then choose a foreground color.
  4. Finish with Enter, Done, or a simple right-click. Esc or Cancel discards the draft.

The path is added to the active Linework layer. Multiple independent paths can share a layer. A path needs at least two points. Press Backspace to remove the last point placed.

Paths remain vector objects. Their control points, pressure, and path properties stay editable until you rasterize the layer.

The seven tools

The examples below were rendered by PhotoCraft’s engine. For editing tools, they show the resulting changes to a path.

SaiCurve smooth curve

Creates an interpolated curve that passes through the placed points. The Width setting controls its base width. Brush mode can taper the ends of new paths.

SaiLine straight segments

Creates a path whose segments run directly between control points. Stroke joins stay rounded. You can edit its points in the same way as SaiCurve points.

SaiPressure 0–200%

Select a point and drag horizontally: drag left to reduce its pressure, right to increase it. The change previews while you drag. A multi-selection lets you adjust several points together.

100% matches the base width; 0% tapers to zero at the point, and 200% doubles the base width. A click without dragging does not change pressure.

SaiWeight path width

Click a path to apply the base width shown in the tool options. SaiWeight changes the overall path width; it does not replace individual point pressure.

SaiColor path color

Choose a foreground color, then click a path to recolor the entire path. Its points, width, and pressure remain unchanged.

SaiPointed hard corner

Click a point to toggle between a smooth join and a hard corner. The stroke outline keeps a rounded join to avoid an unwanted spike in the stroke width.

SaiCombine join paths

Click an endpoint, then an endpoint on another path in the same Linework layer. The paths become one editable path without moving their points. If the endpoints are apart, the new path connects them; if they coincide, the duplicate point is removed. This operation can be undone.

Brush mode SaiCurve option

Brush mode is off by default. When enabled, it sets the first and last point pressure to 0% on SaiCurve paths with at least three points; all inner points stay at 100%. The base width of the main stroke remains unchanged. This applies to new SaiCurve paths only, not SaiLine or existing paths.

Shared editing shortcuts

Point-editing gestures are shared by all SaiLineArt tools. They take priority over the active tool’s normal action.

GestureAction
Click a pointSelect the point.
Shift + click or dragAdd points to the selection. Rectangle selection is additive.
Ctrl + drag a pointMove the point. If several points are selected, move them together.
Ctrl + click a segmentInsert a point on the path. Keep holding Ctrl and drag to move the new point immediately.
Alt + click a pointDelete the point. If it belongs to a multi-selection, delete the selected points.
Alt + click an interior segmentRemove the segment and split the path in two while keeping its control points.
Alt + click the first or last segmentShorten the path by one segment by removing the corresponding endpoint.
Delete / BackspaceDelete all selected points in one operation.
Right-click while holding Ctrl, Alt, or ShiftClear the active SaiLineArt point selection.

Ctrl + drag: the point follows the gesture and the curve is recalculated.

Ctrl + click: add a point on the path at the cursor.

Alt + click a point: delete that point, or the entire selection if it is selected.

Alt + click an interior segment: remove it and split the path while keeping the anchors.

Shift + click/drag: add points to the existing selection; selected anchors are red.

Control skeleton and points

When a modifier is held, hovering over a path reveals its skeleton and handles. SaiPressure always keeps its points visible and shows the skeleton of the hovered path. Cursor hints indicate the action available with Ctrl or Alt.

Selected points are blue in a regular selection. In a multi-selection, selected points and segments between selected points turn red. Starting a new path clears the previous point selection.

Real interface example: SaiPressure selected, with its blue skeleton and visible points.

Transform points with Ctrl+T

Select one or more points from one or more paths, then press Ctrl+T. A bounding frame appears around the selected points. If nothing is selected, SaiLineArt selects the points on paths in the active Linework layer.

  • Drag inside the frame to move the points.
  • Drag a side handle to stretch horizontally or vertically.
  • Drag a corner handle to scale; hold Shift to preserve proportions.
  • Drag outside the frame to rotate around its center; hold Shift to snap in 45° increments.
  • Press Enter to apply or Esc to cancel.

The transform changes point coordinates only. Unselected points stay in place; pressure, color, width, and SaiPointed state are preserved. Curves recalculate during the preview. The whole transform is a single Undo/Redo action.

Note: free deformation of all four corners has not been verified for Linework and is not claimed as supported.

Layers, saving, and rasterizing

Keep paths editable

A Linework layer can contain multiple paths. PhotoCraft documents save their geometry, points, pressure, colors, widths, and corner states. Older documents without saved pressure use 100% by default.

Undo/Redo is available for creating and moving paths, pressure, width, color, point insertion and deletion, SaiPointed, combining paths, and transforms.

Rasterize a layer

In the Layers panel, right-click a Linework layer and choose Rasterize Layer. PhotoCraft renders it to pixels and replaces the vector layer. This can be undone; rasterized content can no longer be edited by its control points.

Launch PhotoCraft and try it

  1. From the PhotoCraft repository, launch the app with CARGO_HOME=/mnt/SSD2/Codex/.tooling/cargo cargo run -p photocraft --offline.
  2. Create a document, choose SaiCurve, place several points, and finish the path.
  3. Try SaiPressure on its points, then use SaiColor or SaiWeight on the path.
  4. Select a few points, press Ctrl+T, then apply or cancel a transform.
  5. Save as `.pcraft`, reopen the document, and confirm the path is still editable.
SaiCurve uses a local cubic spline adapted from the available reference examples. Its geometric similarity has been measured and tested; this does not prove that SaiLineArt has recovered PaintTool SAI’s proprietary formula.
